Your regular task: transcribe, create, cite, verify

Transcribing a source, creating the Source record, adding or updating the people and facts it supports, and citing it against them — this is squarely what the Bridge is built for. This lesson walks the four steps end to end.

Step 1 — Create the source, transcription included

Ask for the Source record and hand over the transcription in the same request:

"Create a Source record from the Birth Certificate template for GRO ref 1895 Q1 Anytown 412, and here's the transcription: [paste text]."

Claude stores the transcription as rich text directly on the Source record and populates whichever record-level template fields you gave it (repository, reference number, that kind of thing) — one request, not two.

Step 2 — Add or update the people and facts

This is ordinary Read-write editing, same mechanics as Lesson 3 — state each addition or correction precisely, rather than "enter what's on the certificate":

"Add John Smith's birth on 12 Mar 1841 at Anytown, and add his father Thomas Smith's occupation as 'Blacksmith', per this certificate."

Step 3 — Cite it against everything it actually supports

Built-in good practice, not just a feature

When you ask Claude to cite a source, it's steered to compare the transcription against what's already in your tree and tell you what the source supports that isn't yet entered — a father's occupation, a mother's maiden name, a residence — rather than citing only the one fact you originally asked about and leaving the rest unrecorded. It will list these and wait for your go-ahead before adding anything beyond your original request. This mirrors sound citation practice you already know — cite every fact a document actually supports — and Claude won't act on the extras silently.

A citation can attach to one specific Fact, or to the record as a whole (a "whole-record" citation — FH's own term for when a source establishes the record itself, e.g. a birth certificate naming both parents makes it a source for the parent-child relationship, not just the birth date). Say which you mean if it isn't obvious from context.

Step 4 — Set the citation's own fields, including per-citation ones

Citation-specific fields: now fully supported

A citation can carry its own field values in the same request that creates it — two families at once:

  • The 4 standard citation fields FH itself always offers, templated source or not: Page ("where within source" — a page/entry number), Text (a transcription-like excerpt scoped to this specific citation), EntryDate, and Assessment (FH's 4-axis reliability rating — Reliable/Questionable, Direct/Indirect, Primary/Secondary, Original/Derivative).
  • A template's own citation-specific fields — the ones that vary per citation even though the Source record itself is shared, like a GRO Index template's Registration District: the source ("GRO Birth Index") stays one record, but that field changes with each entry you cite from it. These are only settable here, on the citation — never on the Source record itself.

So the full request can be one ask: "Cite this GRO Birth Index source against John's birth, Page 412, District Anytown, Assessment Direct and Primary." If a field name collides between the two families, Claude will flag it rather than guess which one you meant.

If you're not sure whether a given template has its own citation-specific fields, ask Claude — "does the GRO Birth Index template have any citation-specific fields?" is a fair, answerable question before you start.

Bonus: your session gets logged automatically

A source-entry session tends to be several small creates and edits in a row — exactly the kind of session where you'd want a record afterwards of what happened. You get one for free: every Read-write Session writes a running log into a Research Note as it goes (this is enforced by the Bridge itself, so it can't quietly be skipped). After a busy session, open that note in FH as your review trail — a second, independent check alongside opening each record yourself, from Lesson 3's routine.

Quick check

Try it now

  1. Pick a real, low-stakes source you have transcribed (or transcribe one now).
  2. Back up, start a Read-write Session, and run Steps 1–3 above on it.
  3. Check whether Claude flagged anything the source supports that you hadn't mentioned — decide whether to add it.
  4. If the template has citation-specific fields, include their values in the citation request itself rather than as an afterthought.
  5. Open the Research Note Claude logged to and review it against what you actually did.
